# Everyline: Rail 맵 제작기

`index.html` 한 파일을 브라우저로 열면 됩니다. 설치나 서버는 필요 없습니다.

결과물은 게임이 읽는 **시나리오 JSON 하나**입니다(개발 지시서 v4.8 10-1).
게임에서는 타이틀 → 챕터 모드(또는 자유 모드) → 맵 선택 → **시나리오 파일 불러오기**로 엽니다.

## 할 수 있는 일

| 탭 | 하는 일 | 시나리오 필드 |
|---|---|---|
| 개요 | 식별자 · 판 · 제목 · 설명, km/단위, 수요·인구 균형, 행정 종류 이름 | `id` `ver` `title` `tag` `desc` `hidden` `bal` `dem.kinds` `map.kmpp` |
| 지도 | 바다 · 육지 · 바깥 땅 · 얕은 바다 칠하기(붓 · 채우기), 산 표시, 참고 이미지 깔기와 자동 변환, 지도 크기, 보정점 두 개로 투영 계산(8-8) | `map.src` `map.w` `map.h` `map.proj` `map.peaks` |
| 노드 | 도시 놓기 · 옮기기, 이름(바꾸면 프리셋 · 주축 · 서브역 참조도 따라감), 인구 가중, 거점, 소도시, 군, 산악 지명, push · pull, 서브역(모도시 · 환승 · 해금) | `nodes` `map.mount` |
| 권역 | 지역 코드 이름과 노드 칠하기, 지역 코드를 정책 권역에 묶기 | `map.regions` `policy.regs` |
| 챕터 | 연도 · 시작자본 · 여론 기준 · 주도 압력 · 시작 차종, 목표 셋 이하, 주축 | `chapters` `axes.gyeongbu` |
| 프리셋 | 2챕터부터 물려받는 역 · 선로(선로 수 · 고속) · 노선(정차역 · 편성 수) | `presets` |
| 검증 | 게임 로더와 같은 `validScen` + 제작기 경고. 오류가 있으면 내보내지 않음(10-6) | |

제작기가 다루지 않는 필드(시대 곡선 · 수단 · 테크트리 · 차종 · 정책 · 재해 · 의뢰 · 사건 …)는
- 새 지도: 한국 시나리오의 값을 빌립니다. 의뢰와 사건은 비우고, 한국 사건을 조건으로 거는 결정은 뺍니다(가람 지방과 같은 처리).
- 연 파일: 연 그대로 다시 내보냅니다. 한국 시나리오를 열고 그대로 저장하면 식별자 · 제목 말고는 같은 내용이 나옵니다(K-2 확인. 지도 PNG는 다시 인코딩되지만 픽셀은 같음).

## 조작

- 휠: 확대 · 축소, 오른쪽(가운데) 끌기 또는 스페이스 + 끌기: 이동, `F`: 전체 보기
- 지도 탭: `1` 육지 `2` 바다 `3` 얕은 바다 `4` 바깥 땅, `[` `]` 붓 크기, Alt + 칠하기 = 바다
- 노드 탭: 노드 끌어 옮기기, `Delete` 지우기
- 프리셋 탭: 노드 누르기 = 역 놓기/빼기, 역에서 역으로 끌기 = 선로, 노선 추가 후 역을 차례로 누르기, `Esc` 노선 편집 끝
- `Ctrl+Z` / `Ctrl+Y`

## 게임 쪽 제약 (지금 빌드 기준)

- **지역 코드 1번**은 게임이 산간 지형 할증(공사비 ×1.8)을 겁니다. 코드에 고정된 값이라 산악 지역을 1번에 두십시오(지시서 1-4 거).
- 목표 지표 `metroShare`(수도권 광역 분담률), `longShare`(장거리 분담률)는 한국 도시 이름에 묶여 있어 새 지도에서는 고를 수 없습니다.
- 「주축 복선화」(`dblRatio`)는 `axes.gyeongbu`를 셉니다. 주축이 비어 있으면 게임은 한국 경부축 이름으로 대신 셉니다.
- 첫 노드가 수도(행정 종류 첫 칸)입니다.
- 첫 챕터는 프리셋 없이 시작합니다(15-28). 2챕터부터는 프리셋이 있어야 로더를 통과하므로, 제작기가 챕터마다 `p<시작연도>` 프리셋을 자동으로 만듭니다.
- 식별자 `korea` · `garam`은 게임에 이미 있어 거부됩니다.

## 지시서와 다른 점

- 10-2는 에디터를 게임 HTML 안의 모드로 넣으라고 합니다. 이 제작기는 독립 파일입니다. 대신 게임의 검증 함수와 기본 데이터를 게임 파일에서 그대로 뽑아 쓰므로, 게임이 바뀌면 다시 뽑아 맞춥니다(아래). 게임 안으로 옮길 때는 `src/app.html`의 편집 코드를 모드 화면에 붙이면 됩니다.
- 10-5는 프리셋 망을 게임 안에서 「프리셋으로 저장」해 만들라고 하지만 그 기능이 아직 게임에 없어서, 제작기에 간단한 프리셋 편집(역 · 선로 · 노선)을 넣었습니다.
- 지도 그림은 RGBA PNG로 저장합니다. 기본 시나리오의 팔레트 PNG보다 조금 큽니다(한국 지도 1.5KB → 12KB).

## 게임이 바뀌었을 때

```sh
node tools/extract.js path/to/everyline-rail-X.Y.Z-bNNN.html   # Playwright 필요
python3 build.py                                                # src → index.html
```

`tools/extract.js`는 게임 HTML에서 `validScen`과 그 닫힌 목록(효과 타입 · 목표 지표 · 의뢰 요구 …)을 `src/validator.js`로,
한국 · 가람 지방 시나리오 객체를 `src/base-kr.json` · `src/base-gr.json`으로 뽑습니다. 화면 왼쪽 위에 검증 기준 게임 판이 보입니다.
